Fetching from the storage provider…
How this page verifies It downloads the CAR by piece CID from the storage provider named in the URL, unpacks events.ndjson and manifest.json, recomputes each event id (NIP-01 sha256 over the canonical array) and checks the Schnorr signature against the author's key. Nothing is trusted from the server beyond the bytes. Libraries load from esm.sh: @ipld/car, @helia/unixfs, @noble/curves, @noble/hashes.
