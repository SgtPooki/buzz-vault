Fetching from the storage provider…
How this page verifies It downloads the CAR from the storage provider URLs carried in this link (the copies recorded at seal time), unpacks events.ndjson and manifest.json, recomputes each event id (NIP-01 sha256 over the canonical array) and checks the Schnorr signature against the author's key. It does not recompute the piece CID in the browser, so a provider could serve a different validly signed transcript; the vault_turn_get agent tool does check the piece CID. The verifier is bundled from the plugin source (src/viewer.ts), no CDN.
